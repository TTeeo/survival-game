🧟 Zombie Game

Juego de supervivencia hecho en Python usando pygame.
El jugador debe sobrevivir a oleadas de zombies que van aumentando en dificultad.

📋 Requisitos

Python 3.10 o superior

⚙️ Instalación

Clonar el repositorio:

git clone https://github.com/TTeeo/zombie-survival.git
cd zombie-game

Crear entorno virtual:

python -m venv venv

Activar entorno virtual:

Windows:
venv\Scripts\activate
Linux / Mac:
source venv/bin/activate

Instalar dependencias:

pip install -r requirements.txt


▶️ Ejecutar el juego
python main.py
